# HRMS - Human Resource Management System

A full-stack Human Resource Management System built using the MERN Stack.

## Features

- Authentication and Authorization
- Employee Management
- Attendance Management
- Leave Management
- Payroll Management
- Task Management
- Calendar Management
- Role & Permission Management
- Notifications
- Reports and Analytics

## Tech Stack

**Frontend**
- React.js
- JavaScript
- Tailwind CSS
- Axios
- React Query

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Project Structure

```text
HRMS/
├── frontend/
├── backend/
├── .gitignore
└── README.md
```

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create `.env` files separately in frontend and backend.

Never upload sensitive credentials to GitHub.

## Deployment

- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
